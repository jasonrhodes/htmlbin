Under ~500 lines · under ~20 files — review density still holds. Prefer this band for feature work (lines matter more if you’re already keeping the file count reasonable).

Creeping toward 1,000 lines or past ~20 files — look for a split now. Past that, comments per unit and first-human waits both fall over hard.

How to split — prefer parallel / non-serial PRs, or push separable work to a follow-up issue. Don’t stack everything behind one mega-diff.
